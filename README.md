# SpaceLens — iOS 离线只读空间分析与文件分类浏览器

一个开源、纯离线、纯只读的 iOS 存储空间分析与文件分类 App，专为带有 **TrollStore / TrollStore Lite** 或越狱环境的 iOS 16+ 设备打造。

## 安全底线
- **零网络代码：** 不发起任何网络请求，不开任何本地监听端口。
- **零外部入口：** 不注册 URL Scheme，不内嵌 WebView，不注入任何其他 App。
- **纯只读元数据扫描：** 使用 POSIX `opendir` + `lstat` 仅读取文件名、后缀、体积与修改时间，**不解码文件内容，不包含任何删除/修改逻辑**，杜绝误删相册或系统文件风险。

## 功能
1. **本机容量总览：** 实时显示总容量、已用、可用空间与扫描进度。
2. **安卓风格文件分类：** 自动归类 **视频 / 图片 / 音频 / 文档 / 压缩与安装包（`.zip/.ipa/.deb`） / 其它**，列出每类总大小、文件数及体积 Top 排行。
3. **中文应用目录：** 自动将 `/var/mobile/Containers/Data/Application/<UUID>` 映射为中文 App 名称，展示每个应用的 `Documents / Caches / Library` 占比，支持逐级进入目录查看文件大小。
4. **全机大文件排行：** 快速定位全机 `≥ 20 MB` 的大文件，点击即可复制完整路径（方便按需在系统或 Filza 中精准处理）。
